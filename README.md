# Berman Business Finder

A small-scale business recommendation project inspired by Yelp.  
Built with **Java**.

---

## Features

- Find similar businesses based on category, location, and ratings  
- Simple and clean user interface using Java UI  
---

## Dataset

This project uses the **Yelp Academic Dataset**.  
The dataset is **not included** in this repository due to GitHub size limits.

To run locally:

1. Download the Yelp dataset from [Yelp Dataset](https://www.yelp.com/dataset)
2. Place `yelp_academic_dataset_business.json` in the `/data` folder
